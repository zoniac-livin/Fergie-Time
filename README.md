# Football Investor

A web-based football management and market simulation game. Build a 7-player squad through a **blind draft**, watch the identities get revealed, then manage your players through a **10-year market simulation** driven by real Transfermarkt valuation history. Your goal: finish with the highest club net worth.

Inspired by the GOAL "Front Three" YouTube challenge. This is an unofficial fan project.

## How it plays

1. **Blind Draft.** Start with a budget of **€250,000,000**. Each card shows only a player's position, age, price and draft-season stats. No name, face, club or nationality. Fill exactly 1 GK, 2 DEF, 2 MID and 2 ATT. You get 3 skips. Every pick permanently spends part of your budget.
2. **Squad Locked.** Once you have all 7 players, the squad is final.
3. **The Reveal.** The 7 cards are turned over one by one, showing each player's name and photo. Your starting club value is your remaining budget plus the market value of your squad.
4. **10-Year Simulation.** Each year, every player's value follows the real Transfermarkt valuation history from the dataset. You decide whether to **hold** or **sell** each player. Sold players turn into cash at their current market value.
5. **Results.** Your final net worth, a rank title, your best investment, your worst flop, a net worth chart and a history card for every player.

| Final net worth | Rank |
| --- | --- |
| Above €500M | Master Negotiator |
| €200M to €500M | Transfer Strategist |
| Below €200M | Relegation Fodder |

## Tech stack

- Next.js (App Router) and React
- TypeScript (strict)
- Tailwind CSS with design tokens in CSS variables
- Zustand for game state (persisted, SSR-safe)
- Framer Motion for animation
- Vitest for tests
- Node.js, `tsx` and `csv-parse` for the data pipeline

## Getting started

You need [Node.js](https://nodejs.org) (LTS) and [pnpm](https://pnpm.io).

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

| Command | What it does |
| --- | --- |
| `pnpm dev` | Start the development server |
| `pnpm build` | Create a production build |
| `pnpm test` | Run the test suite |
| `pnpm lint` | Run ESLint |
| `pnpm generate-pool` | Rebuild `src/data/players.json` from the raw data (see below) |

## The player data

The game reads a ready-made player pool from `src/data/players.json`, which is committed to the repository, so you do not need the raw data to play.

The pool is generated by `scripts/generate-pool.ts` from the Transfermarkt dataset CSV files. The raw files are large and are **not** included in this repository. To regenerate the pool, put these four files in a top-level `Data/` folder and run `pnpm generate-pool`:

- `players.csv.gz`
- `appearances.csv.gz`
- `games.csv.gz`
- `player_valuations.csv.gz`

The pipeline is deterministic: the same input files always produce the same output. Its main rules:

- Players must have played in one of ten top leagues (Premier League, La Liga, Serie A, Bundesliga, Ligue 1, Primeira Liga, Eredivisie, Belgian Pro League, Super Lig, Scottish Premiership).
- Their highest market value must be at least €10M.
- Each player gets one draft season (2014 to 2018): the earliest season with at least 400 minutes played and a valid market valuation.
- Each player gets 11 yearly values (Year 0 to Year 10). When real valuations run out, the last known value falls by 25% per year.

## Design principles

- **Rules live in the engine.** Game logic is pure functions. UI components never calculate money and never change state directly; they call store actions and read selectors.
- **Deterministic.** There is no randomness in market values. The draft order comes from a seeded random generator.
- **One source of truth for value.** A player's current value always comes from `yearly_values[currentYear]`. Net worth is your cash plus the value of the players you still hold.
- **A truly blind draft.** Draft cards are built from reduced view objects that never contain a player's name, id, photo or draft season. Tests check this with sentinel strings.
- **No future leaks.** Nothing about later years is shown during the simulation, including chart scales.
- **Accessible.** Keyboard operable, visible focus, text and symbols for gains and losses (not colour alone), and support for reduced motion.

## Known limitations

- The data has no club, nationality or clean-sheet information, so none is shown.
- Players drafted in 2017 and 2018 lose value in the late years partly because the dataset ends, not only because of the market.
- Percentage returns favour very cheap players, because every player in the pool peaked above €10M at some point.
- The interface uses placeholder styling. A design pass is planned.
- Some animations are not built yet (reveal flip, number transitions, results count-up).
- Rank thresholds are provisional and may be tuned after more play-testing.
- Player photos are loaded from the image links in the dataset and can fail. A silhouette is shown instead.

## Roadmap

- A choice of 5 players per draft round instead of skips
- Transfer windows (sell and buy in set years)
- A rebalanced budget and rank thresholds based on simulation
- Full animation and visual design pass
